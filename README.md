# 🎤 Speaking Hub — UTAS-Nizwa GFP · General English (GE1)

موقع تفاعلي ثنائي اللغة (عربي/إنجليزي) لمقرر الإنجليزية العامة (GE1) في البرنامج التأسيسي بجامعة التقنية والعلوم التطبيقية بنزوى.
A bilingual (Arabic/English) interactive class hub for the General English (GE1) course in the General Foundation Program at UTAS-Nizwa.

---

## 1. وصف المشروع · Project Description

منصّة صفحة واحدة تجمع كل ما يحتاجه طالب التأسيس في مكان واحد:
- معلومات المدرّس، لوائح الجامعة والصف، معلومات الجامعة، التقويم الأكاديمي، المكتب وخريطة الحرم، الإعلانات، مواد المحاضرات، الأسئلة الشائعة، وروابط التواصل.
- **٥ أنشطة صفّية تفاعلية**: الجرة العجيبة، كرة الأسئلة، سؤال اليوم (عجلة أرقام)، تحدّي ٣٠ ثانية، وتحفيز اليوم.
- تصميم داكن عصري مع تأثيرات حركة (تدرّجات متحرّكة، ضوء يتبع المؤشّر، حافة ضوئية، شهب، ظهور بضبابية).
- **وضع المالك** برمز سري: الموقع للقراءة فقط للجميع، والتعديل متاح للمالك فقط.

A single-page hub bringing everything a foundation student needs together: instructor info, university & classroom guidelines, university overview, academic calendar, office + campus map, announcements, lecture materials, FAQ, and social links — plus 5 interactive classroom activities, a modern dark UI with motion effects, and an owner-only edit mode.

**التقنيات · Tech:** HTML5 · CSS3 · Vanilla JavaScript (بدون أطر عمل / no frameworks). خطوط Google Fonts.

## 4. طريقة التشغيل · Getting Started

### محليًا · Locally
الملفات الثلاثة يجب أن تبقى **في نفس المجلد**:
```
speaking-hub/
├── index.html
├── styles.css
└── app.js
```
- الطريقة الأسهل: افتحي `index.html` مباشرة في المتصفّح.
- الطريقة المفضّلة (تتجنّب قيود المتصفّح): شغّلي خادمًا محليًا بسيطًا:
```bash
# Python
python3 -m http.server 8000
# ثم افتحي:  http://localhost:8000

# أو Node
npx serve
```

### الرفع · Deploy
ارفعي المجلد كاملًا (بالملفات الثلاثة) إلى أي استضافة ملفات ثابتة:
- **Vercel:** اسحبي المجلد إلى لوحة Vercel، أو `vercel` عبر الطرفية.
- **Netlify:** اسحبي المجلد إلى Netlify Drop.
- **GitHub Pages:** فعّلي Pages من إعدادات المستودع.

### وضع المالك · Owner mode
- زر **🔒** في الشريط العلوي. الرمز الافتراضي: `utas2026`.
- بعد إدخال الرمز تظهر أزرار التعديل ✏️ ويُحفظ الوضع على جهازك.
- لتغيير الرمز: الرمز مخزّن كبصمة مشفّرة داخل `app.js` (الثابت `OWNER_HASH`)، غيّريه بحساب بصمة رمزك الجديد.

## 5. قاعدة البيانات · Database

**الحالة الحالية:** لا توجد قاعدة بيانات خلفية (backend). يستخدم الموقع **تخزين المتصفّح `localStorage`** لحفظ تعديلات المالك على جهازه.

| المفتاح (localStorage key) | المحتوى |
|---|---|
| `fh_inst` | بيانات المدرّس (الاسم، المسمّى، الصورة، الإحصائيات، المحاور، المواد، الخط الزمني) |
| `fh_rules` | لوائح الجامعة والصف |
| `fh_uni` | نبذة الجامعة وبطاقاتها |
| `fh_cal` | التقويم الأكاديمي |
| `fh_office` | بيانات المكتب والإرشادات |
| `fh_map` | صورة خريطة الحرم وموقع الدبّوس |
| `fh_extra` | الإعلانات + المواد + الأسئلة الشائعة |
| `fh_socials` | روابط التواصل |
| `fh_owner` | حالة وضع المالك على الجهاز |

> ⚠️ لأن الحفظ محلّي لكل جهاز، تعديلات المالك تظهر على متصفّحه فقط ولا تصل لبقية الطلاب. لجعل المحتوى مشتركًا للجميع، إمّا تُثبَّت القيم داخل `app.js`، أو يُضاف backend.

**الخيار المستقبلي (Supabase):** لتحويله إلى محتوى مشترك حقيقي مع تسجيل دخول للمالك:
- جدول `content(section text primary key, data jsonb, updated_at timestamptz)` لحفظ كل قسم.
- جدول `storage bucket` لصور الخريطة/المدرّس.
- **Row Level Security:** قراءة عامة، وكتابة لمالك مُصادَق فقط (Supabase Auth).

## 6. المتغيّرات السرّية · Environment Variables

**الحالة الحالية:** لا يحتاج المشروع أي متغيّرات سرّية (ثابت بالكامل).

**عند إضافة Supabase مستقبلًا** ستحتاجين (مثال في ملف `.env`):
```bash
# عام (يظهر في المتصفّح — آمن مع RLS)
VITE_SUPABASE_URL="https://<project-ref>.supabase.co"
VITE_SUPABASE_ANON_KEY="<anon-public-key>"

# سرّي (خادم فقط — لا يُرفع للمتصفّح أبدًا)
SUPABASE_SERVICE_ROLE_KEY="<service-role-key>"
```
> لا ترفعي ملف `.env` إلى GitHub — أضيفيه إلى `.gitignore`. على Vercel/Netlify أضيفي هذه القيم في إعدادات Environment Variables.

## 7. المميزات الحالية · Current Features

- 🌍 **ثنائي اللغة** عربي/إنجليزي مع تبديل ناعم ودعم كامل لـ RTL.
- 🌙 **وضع داكن** ثابت وتصميم زجاجي عصري باللوحة (كريمي/رملي + مرجاني + أزرق عميق).
- 🔒 **وضع المالك** برمز سري — الموقع للقراءة فقط للجميع، والتعديل للمالك.
- ✏️ **تعديل شامل** لكل الأقسام مع حفظ محلّي: المدرّس (بالصورة رفعًا أو رابطًا)، اللوائح، الجامعة، التقويم، المكتب، الإعلانات، المواد، الأسئلة، والروابط.
- 🗺️ **خريطة حرم تفاعلية** بأسلوب خرائط قوقل: تكبير/تصغير (عجلة/لمس/أزرار)، سحب، دبّوس دقيق بمساحة إمساك كبيرة، خطوط تصويب، عدسة مكبّرة، إحداثيات لحظية، وإعادة تعيين.
- 🎮 **٥ أنشطة صفّية:** الجرة العجيبة، كرة الأسئلة، سؤال اليوم (عجلة أرقام ١–قابلة للتعديل + ١٠٠+ سؤال)، تحدّي ٣٠ ثانية (مؤقّت ثلاثي الأبعاد)، وتحفيز اليوم.
- ✨ **تأثيرات حركة:** نص متدرّج متحرّك، لمعان الأزرار، ضوء يتبع المؤشّر، حافة ضوئية، شهب، وظهور بضبابية — مع احترام «تقليل الحركة».
- 🔍 بحث للانتقال بين الأقسام · 🎉 كونفيتي ومؤثّرات صوت خفيفة · 📱 تصميم متجاوب (Mobile-first).
- ♿ يحترم `prefers-reduced-motion` ويعمل باللمس والماوس.

## 8. المشاكل المعروفة · Known Issues

- 💾 **الحفظ محلّي لكل جهاز** (localStorage) — تعديلات المالك لا تُشارَك تلقائيًا مع بقية الزوّار.
- 🔓 **قفل المالك رادع وليس حماية مطلقة** — في ملف ثابت يمكن تجاوزه عبر «مصدر الصفحة». الحماية الحقيقية تحتاج backend/تسجيل دخول.
- 🖼️ **حجم الصور:** الصور المرفوعة (المدرّس/الخريطة) تُخزَّن كـ base64 في localStorage؛ الصور الكبيرة جدًا قد تصطدم بحدّ التخزين (~5MB) — يُنصح برفع صور معقولة الدقّة.
- 🌐 **خطوط Google Fonts** تحتاج اتصالًا بالإنترنت؛ بدون اتصال يستخدم المتصفّح خطوطًا احتياطية.
- 🔢 **تواريخ التقويم** الافتراضية «يُحدَّد لاحقًا» — تُضبط يدويًا من زر تعديل التقويم.
