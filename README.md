# 🎓 بورتفوليو فيصل · Faisal's Portfolio — UTAS-Nizwa GFP · General English (GE2)

موقع تفاعلي ثنائي اللغة (عربي/إنجليزي) للأستاذ فيصل خليفة الشامخي، مدرّس مقرر الإنجليزية العامة (GE2) في البرنامج التأسيسي بجامعة التقنية والعلوم التطبيقية بنزوى.
A bilingual (Arabic/English) interactive portfolio for Mr. Faisal Khalifa Al Shamakhi, General English (GE2) instructor in the General Foundation Program at UTAS-Nizwa.

---

## 1. وصف المشروع · Project Description

منصّة صفحة واحدة تجمع كل ما يحتاجه طالب التأسيس في مكان واحد:
- معلومات المدرّس، لوائح الجامعة والصف، معلومات الجامعة، التقويم الأكاديمي، المكتب وخريطة الحرم، الإعلانات، مواد المحاضرات، الأسئلة الشائعة، وروابط التواصل.
- **٥ أنشطة صفّية تفاعلية**: الجرة العجيبة، كرة الأسئلة، سؤال اليوم (عجلة أرقام)، تحدّي ٣٠ ثانية، وتحفيز اليوم.
- **مسابقة كاهوت** مباشرة (بطاقة تفتح Kahoot.it من الجوال).
- **لغز كلمات متقاطعة** تفاعلي بخلفية حروف متساقطة، مبني بالكامل على مفردات ومحتوى UTAS.
- **مساعد GFP الذكي (شات بوت)**: يجاوب على أسئلة الطلاب عن البرنامج التأسيسي (النشرة الرسمية)، ويحوّل أي سؤال ما قدر يجاوب عليه إلى إيميل مباشر للمدرّس.
- تصميم فاتح عصري مسطّح (بدون تدرّجات بالخلفية) بلوحة ألوان: كريمي فاتح + كحلي داكن + برتقالي مرجاني.
- **وضع المالك** بتسجيل دخول آمن عبر إيميل + رابط سحري (Supabase Auth) — الموقع للقراءة فقط للجميع، والتعديل متاح للمالك فقط.

A single-page hub bringing everything a foundation student needs together: instructor info, university & classroom guidelines, university overview, academic calendar, office + campus map, announcements, lecture materials, FAQ, and social links — plus 5 interactive classroom activities, a live Kahoot quiz card, a bilingual crossword puzzle game with a falling-letters background, a GFP Q&A chatbot (with an "email the instructor" fallback), a flat modern light UI, and a secure owner-only edit mode.

**التقنيات · Tech:** HTML5 · CSS3 · Vanilla JavaScript (بدون أطر عمل / no build step). خطوط Google Fonts (Space Grotesk / Poppins / Cairo). مصادقة المالك عبر **Supabase Auth** (Magic Link).

## 4. طريقة التشغيل · Getting Started

### محليًا · Locally
الملفات يجب أن تبقى **في نفس المجلد**:
```
profile/
├── index.html
├── styles.css
├── app.js
├── crossword.html      ← صفحة لغز الكلمات المتقاطعة (مستقلة)
└── chatbot.html         ← صفحة مساعد GFP الذكي (مستقلة)
```
- الطريقة الأسهل: افتحي `index.html` مباشرة في المتصفّح.
- الطريقة المفضّلة (تتجنّب قيود المتصفّح): شغّلي خادمًا محليًا بسيطًا:
```bash
# Python
python3 -m http.server 8000
# ثم افتحي:  http://localhost:8000

# أو Node
npx serve
```

### الرفع · Deploy
المشروع مربوط بـ Vercel وينشر تلقائيًا عند تحديث الفرع الرئيسي على GitHub (بدون خطوة بناء / build step). لرفعه في مكان آخر، ارفعي كل الملفات أعلاه كما هي إلى أي استضافة ملفات ثابتة (Netlify، GitHub Pages، إلخ).

### وضع المالك · Owner mode
- زر **🔒** في الشريط العلوي.
- يُدخِل المالك إيميله المسجَّل مسبقًا في Supabase → تصله رسالة فيها **رابط سحري (Magic Link)** → بمجرد الضغط عليه يسجَّل دخوله تلقائيًا وتظهر أزرار التعديل ✏️.
- **فقط الإيميل المُنشأ مسبقًا في Supabase (Authentication → Users) يقدر يسجّل دخول** — `shouldCreateUser:false` بمعنى ما أحد غيره يقدر يسوي حساب جديد.
- التفاصيل الكاملة (إنشاء المستخدم، ضبط Site URL / Redirect URLs) موجودة في `SUPABASE_SETUP.md`.

## 5. قاعدة البيانات · Database

**الحالة الحالية:** Supabase تُستخدم **فقط للمصادقة (تسجيل دخول المالك عبر Magic Link)** — لا يوجد جدول بيانات يخزّن محتوى الموقع. محتوى الأقسام (المدرّس، اللوائح، التقويم...) لا يزال يُحفظ محليًا عبر **`localStorage`** على جهاز المالك فقط، تمامًا كما كان قبل إضافة Supabase.

| المفتاح (localStorage key) | المحتوى |
|---|---|
| `fh_inst` | بيانات المدرّس (الاسم، المسمّى، الصورة، الإحصائيات، المحاور، المواد، الخط الزمني) |
| `fh_rules` | لوائح الجامعة والصف |
| `fh_uni` | نبذة الجامعة وبطاقاتها |
| `fh_cal` | التقويم الأكاديمي |
| `fh_office` | بيانات المكتب والإرشادات |
| `fh_map` | صورة خريطة الحرم وموقع الدبّوس |
| `fh_extra` | الإعلانات + المواد + الأسئلة الشائعة |
| `fh_socials` | روابط التواصل |

> ⚠️ لأن حفظ المحتوى محلّي لكل جهاز، تعديلات المالك على الأقسام تظهر على متصفّحه فقط ولا تصل لبقية الزوّار تلقائيًا. لجعل المحتوى مشتركًا للجميع، إمّا تُثبَّت القيم داخل `app.js` مباشرة، أو يُضاف جدول بيانات فعلي في Supabase (مثل `content(section text primary key, data jsonb)` مع Row Level Security: قراءة عامة وكتابة للمالك المُصادَق فقط).

## 6. المتغيّرات / المفاتيح · Environment & Keys

المشروع بدون خطوة بناء (no build step)، فمفاتيح Supabase العامة **مكتوبة مباشرة داخل `app.js`** (وهذا آمن لأنها مفاتيح publishable/anon مصمَّمة للظهور في المتصفّح، وليست سرّية):

```js
const SUPABASE_URL = "https://cjytpicdsedcgqauatkp.supabase.co";
const SUPABASE_ANON_KEY = "sb_publishable_...";
```

> ⚠️ لا تضيفي أبدًا مفتاح `service_role` (السرّي) هنا أو في أي ملف يُرفع للمتصفّح — هذا المفتاح فقط للاستخدام من خادم (لا يوجد خادم حاليًا بهذا المشروع).

## 8. المشاكل المعروفة · Known Issues

- 💾 **محتوى الأقسام محفوظ محلّيًا لكل جهاز** (localStorage) — تعديلات المالك على النصوص لا تُشارَك تلقائيًا مع بقية الزوّار (Supabase هنا للمصادقة فقط، وليست لتخزين المحتوى — راجع القسم ٥).
- ✉️ **رابط الدخول السحري (Magic Link)** يحتاج أن يكون Site URL و Redirect URLs في إعدادات Supabase مطابقة تمامًا لرابط الموقع المنشور على Vercel، وإلا الرابط ما يشتغل.
- 🖼️ **حجم الصور:** الصور المرفوعة (المدرّس/الخريطة) تُخزَّن كـ base64 في localStorage؛ الصور الكبيرة جدًا قد تصطدم بحدّ التخزين (~5MB).
- 🤖 **الشات بوت مبني على مطابقة كلمات مفتاحية** (وليس ذكاء اصطناعي حقيقي) — يجاوب فقط على الأسئلة القريبة من قاعدة أسئلته، وأي سؤال خارجها يُحوَّل لإيميل المدرّس.
- ✉️ **زر "أرسل سؤالي لمستر فيصل"** يفتح تطبيق البريد الافتراضي على جهاز الطالب (`mailto:`) — يحتاج أن يكون عنده تطبيق بريد مُهيَّأ على جهازه ليعمل.
- 🌐 **خطوط Google Fonts** تحتاج اتصالًا بالإنترنت؛ بدون اتصال يستخدم المتصفّح خطوطًا احتياطية.
